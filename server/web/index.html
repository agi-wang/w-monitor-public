一键部署单台设备

在目标 Linux 设备执行下方命令。安装器验证发布来源后，会创建匿名空间和公开页，在终端打印私密恢复 Key 与访问地址，并启动 Lite Agent。

此流程会自动公开首台设备的名称、状态和基础资源占用。完整采集数据保持私有；恢复 Key 请勿分享。需预先安装 curl、Bash 和 SHA-256 校验工具，更新仍须手动执行。

恢复监控空间

输入此前保存的私密口令。恢复后，设备会归入同一空间。

保存新的恢复口令

只显示这一次。保存后，你可以跨浏览器找回这个空间。

接入一台设备

Linux AMD64 / ARM64。先安装 curl、Bash 和 SHA-256 校验工具；安装器会校验下载文件。请以你允许进行采集的系统用户运行。

命令含私密接入凭据，请勿公开。轮换接入凭据不影响已注册设备；Agent 保持前台运行，更新须在本机手动执行。
